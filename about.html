About Cyber Security Link Alert

This project is designed to raise awareness about link-based cyber threats like phishing and scams. Users can scan suspicious links and see if they are safe or unsafe using an offline system.

  • Features: Login, Link Checker, History Report, User Biodata, Offline Storage
